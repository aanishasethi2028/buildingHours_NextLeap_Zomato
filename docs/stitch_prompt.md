# UI Design Prompt for Google Stitch

Copy and paste the following prompt into Google Stitch to generate the frontend design for the project:

***

**Role**: You are an expert frontend developer and UI/UX designer.

**Objective**: Create a professional, modern, and highly responsive web frontend for an AI-powered Restaurant Recommendation System inspired by Zomato. 

**Design Inspiration & Aesthetics**:
- **Theme**: Zomato.com (professional, premium feel, clean typography).
- **Colors**: Use Zomato's signature red (or a similar vibrant primary color) for primary actions and accents, combined with clean whites, subtle grays for backgrounds, and dark grays/blacks for text to ensure high contrast and readability.
- **Styling**: Implement modern web design best practices (e.g., subtle drop shadows, glassmorphism where appropriate, rounded corners, and micro-animations for hover states).

**Layout Requirements**:
1. **Header**: A full-width, complete, and prominent navigation header containing the app logo/branding, and standard navigational links.
2. **Main Content Area (No Sidebar)**: 
   - **Filter Panel**: Place the filter panel in the **main window** (top or center-aligned) rather than on a side panel. 
   - The filter panel must collect the following preferences from the user:
     - `Location` (Text input or dropdown, e.g., Delhi, Bangalore)
     - `Budget` (Dropdown or toggle buttons: low, medium, high)
     - `Cuisine` (Text input or multi-select, e.g., Italian, Chinese)
     - `Minimum Rating` (Numeric threshold, e.g., 4.0+)
     - `Additional Preferences` (Text area for soft constraints like "family-friendly, quick service")
3. **Recommendation Results Section**: 
   - Display a batch-level summary paragraph generated by the AI at the top of the results.
   - Display the recommended restaurants as a grid or list of **Result Cards**. 
   - Each card must display:
     - A placeholder for a restaurant image (ensure it handles missing images gracefully).
     - **Restaurant Name** (prominent heading)
     - **Cuisine**
     - **Rating** (highlighted clearly, maybe with a star icon)
     - **Estimated Cost**
     - **AI Explanation**: A dedicated section or distinct text styling within the card showing the AI-generated natural language explanation of why it fits the user's preferences.

**Data Models (for integration)**:
Ensure the UI components map easily to the following JSON structures:

*Input (UserPreferences)*:
```json
{
  "location": "string",
  "budget": "low | medium | high",
  "cuisine": "string",
  "min_rating": 0.0,
  "additional_preferences": "string"
}
```

*Output (RecommendationBatch)*:
```json
{
  "summary": "AI generated summary of the results...",
  "recommendations": [
    {
      "restaurant": {
        "id": "string",
        "name": "string",
        "location": "string",
        "cuisine": "string",
        "cost": "string",
        "budget_tier": "string",
        "rating": 4.5
      },
      "rank": 1,
      "explanation": "AI generated explanation..."
    }
  ]
}
```

**Technical Requirements**:
- Use clean, semantic HTML5 and vanilla CSS (or standard framework depending on Stitch's default stack).
- Ensure the layout is fully responsive (mobile, tablet, and desktop views).
- Implement interactive elements with hover effects to make the interface feel dynamic and alive.
- Do not use generic, basic styling—strive for a "wow" factor that feels like a state-of-the-art consumer product.

***
